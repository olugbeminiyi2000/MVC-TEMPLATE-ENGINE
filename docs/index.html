V1 Template Engine

A lightweight Python template engine built without an AST — using a linear state machine, indentation-based scope tracking, and a custom linked-list iterator for loops.

Python 3 1 dependency: regex Variables Conditionals Loops NOT · AND · OR Nested structures

Quick Start

Write your template in a .txt file:

template.txt
Hello, {{ username }}!

{% IF show_items %}
    Your items:
    {% FOR item IN items %}
        - {{ item }}
    {% ENDFOR %}
{% ELSE %}
    No items to show.
{% ENDIF %}

Pass a context_data dictionary to the engine:

Python
from engine.main_engine import run_template_engine

context_data = {
    "username": "Emmanuel",
    "show_items": True,
    "items": ["Apples", "Oranges", "Mangoes"],
}

run_template_engine("template.txt", context_data)

Run from the project root:

Terminal
python -m engine.main_engine
Note: The template filename is resolved relative to the project root directory. run_template_engine prints the rendered output directly.

Variables

Use double curly braces to insert a value from context_data or from the current loop scope.

Syntax
{{ variable_name }}

Flexible whitespace

All of these are valid and produce the same output.

Template
{{ name }}
{{name}}
{{  name  }}

None renders as empty

If a variable's value is None, an empty string is output — no visible text.

Python
context_data = { "title": None }
# {{ title }} → ""

Variable names must be valid Python identifiers — see Variable Names for the rules.

Conditionals

Syntax
{% IF condition %}
    ...
{% ELIF other_condition %}
    ...
{% ELSE %}
    ...
{% ENDIF %}
Rule Detail
{% ELIF %} and {% ELSE %} Optional. Multiple ELIF branches are supported.
Branch exclusivity Once one branch is true, all remaining ELIF and ELSE branches are skipped.
Truthiness Follows Python rules: 0, "", [], {}, None, False are all falsy.
Keywords Must be uppercase: IF, ELIF, ELSE, ENDIF.
Nesting Conditions can be nested inside loops and other conditions to any depth.

Multiple ELIF branches

Template
{% IF is_admin %}
    Admin panel
{% ELIF is_moderator %}
    Moderator panel
{% ELIF is_member %}
    Member dashboard
{% ELSE %}
    Please log in.
{% ENDIF %}

Logic Operators

Three operators are available inside {% IF %} and {% ELIF %} conditions.

NOT

Negates the truthiness of the variable that immediately follows it.

AND

True only when both the left and right sides are truthy.

OR

True when either the left or the right side is truthy.

Evaluation order: NOT is applied first, then AND, then OR. This matches standard boolean precedence.

Example

Template
{% IF NOT is_banned AND is_active OR is_admin %}
    Access granted.
{% ENDIF %}

Evaluates as: (NOT is_banned AND is_active) OR is_admin

Combining NOT with AND

Template
{% IF NOT has_errors AND is_complete %}
    Ready to submit.
{% ELSE %}
    Fix issues before submitting.
{% ENDIF %}

Loops

Syntax
{% FOR item IN collection %}
    {{ item }}
{% ENDFOR %}
Rule Detail
Loop variable item is available inside the loop body as a variable.
Iterable collection must be a key in context_data whose value is a supported iterable type.
Nested loops A loop variable that is itself iterable can be used as the iterable of an inner loop.
Conditions inside loops {% IF item %} and the full condition syntax work inside any loop body.
Keywords Must be uppercase: FOR, IN, ENDFOR.

Loop with a condition on the loop variable

Template
{% FOR score IN scores %}
    {% IF score %}
        Score: {{ score }}
    {% ELSE %}
        Zero score.
    {% ENDIF %}
{% ENDFOR %}

Nested loop with empty-group guard

Template
{% FOR group IN groups %}
    {% IF group %}
        {% FOR item IN group %}
            Item: {{ item }}
        {% ENDFOR %}
    {% ELSE %}
        Empty group.
    {% ENDIF %}
{% ENDFOR %}
Python
context_data = {
    "groups": [[], [4, 5, 6], [7, 8, 9]],
}

Supported Iterable Types

The value of the iterable key in context_data must be one of the five Python types below.

Type Iteration behaviour Example value
list Elements in order [1, 2, 3]
tuple Elements in order (10, 20, 30)
dict Keys only, insertion order {"a": 1, "b": 2}
set Arbitrary order {100, "biscuits"}
str Character by character "hello"

Indentation Rules

Every block tag — {% IF %}, {% ELIF %}, {% ELSE %}, {% ENDIF %}, {% FOR %}, {% ENDFOR %} — must be placed at a column that is a multiple of 4 spaces (0, 4, 8, 12, …).

Valid indentation
{% IF condition %}           ← column 0  (0 × 4)
    content
    {% FOR item IN items %}   ← column 4  (1 × 4)
        {{ item }}
    {% ENDFOR %}               ← column 4  (1 × 4)
{% ENDIF %}                    ← column 0  (0 × 4)
PlacementError is raised if any block tag is not at a column that is a multiple of 4.

Variable Names

Variable names must follow Python identifier rules.

Rule Detail
First character A letter (A–Z, a–z) or underscore (_)
Remaining characters Letters, digits (0–9), or underscores
Pattern [A-Za-z_][A-Za-z0-9_]*

Valid names

username   _count   item1   my_list   A

Invalid names

1item   my-list   user name   @data

Rendering Pipeline

Every call to run_template_engine() passes through eight stages in order. Each stage is a separate module.

1
Load
Read the template file from disk and return it as a string.
engine/file_loader.py
2
Pattern Match
Compile all regex patterns into a single combined expression and find every {{ }}, {% IF %}, {% FOR %}, etc. in the template.
engine/pattern_matcher.py
3
Error Check
Validate each matched pattern against stricter patterns that enforce correct syntax. Raises ConditionError, LoopError, or VariableError on any malformed tag.
engine/error_checker.py
4
Structure Check
Verify every {% IF %} has a matching {% ENDIF %} and every {% FOR %} has a matching {% ENDFOR %}. Raises StructureError on unclosed blocks.
engine/structure_checker.py
5
Parse
Split the template string into a flat ordered list of (static text, match object) component pairs. This is the data structure the renderer walks.
engine/parser.py
6
Validate
Walk the component list and confirm every variable and iterable used in the template exists in context_data or within the scope of an enclosing loop. Raises VariableError for any missing name.
engine/validator.py
7
Iterable Manager
Convert every top-level iterable in context_data into a custom linked list with a stagnant head (for reset) and a traversal head (for iteration).
engine/iterable_manager.py
8
Render
Walk the component list. For each component: evaluate conditions using the logic-node chain, advance loop iterators via the linked list, substitute variables, and accumulate the rendered output string.
engine/renderer.py

Error Reference

Exception Raised when
VariableError A variable used in the template is not found in context_data or the current loop scope.
ConditionError An {% IF %} or {% ELIF %} tag is not written correctly — wrong spacing, missing keyword, or invalid variable name.
LoopError A {% FOR %} or {% ENDFOR %} tag is not written correctly.
StructureError An {% IF %} block has no matching {% ENDIF %}, or a {% FOR %} has no matching {% ENDFOR %}.
PlacementError A block tag is not at a column that is a multiple of 4 spaces.

Full Example

This is the template shipped with the engine (template.txt) and the context data that drives it.

context_data (Python)
context_data = {
    "A":          True,
    "B":          False,
    "C":          True,
    "D":          True,
    "E":          True,
    "F":          False,
    "first_name": "Emmanuel",
    "last_name":  "Obolo",
    "farms":      [[], [4, 5, 6], [7, 8, 9]],
    "tomatoes":   {"tomato1": 1, "tomato2": 2, "tomato3": 3},
    "containers": (10, 11, 12),
    "labels":     {100, "biscuits", "Orange"},
}
template.txt
User Profile: {{ first_name }} {{ last_name }}

{% IF E %}
    Inventory Check:
    {% FOR container IN containers %}
        Container ID: {{ container }}
        {% IF D %}
            {% FOR farm IN farms %}
                {% IF farm %}
                    Farm Contents:
                    {% FOR num IN farm %}
                        Item {{ num }}
                    {% ENDFOR %}
                {% ELIF C %}
                    Farm is empty but C is true.
                {% ELSE %}
                    No farm data.
                {% ENDIF %}
            {% ENDFOR %}
        {% ELSE %}
            No farms checked.
        {% ENDIF %}
    {% ENDFOR %}
{% ELSE %}
    Inventory not available.
{% ENDIF %}

Label Report:
{% IF F %}
    No labels to display.
{% ELSE %}
    {% FOR label IN labels %}
        Label Entry: {{ label }}
        {% IF A %}
            {% FOR container IN containers %}
                Container {{ container }} linked to {{ label }}
            {% ENDFOR %}
        {% ELIF C %}
            Containers not linked.
        {% ENDIF %}
    {% ENDFOR %}
{% ENDIF %}
